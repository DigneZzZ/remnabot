# Массовые операции с пользователями в отрядах

## Описание

Функционал массового добавления и удаления всех пользователей в/из отряда.

## Возможности

### Добавление всех пользователей
- **Кнопка**: `➕ Добавить ВСЕХ пользователей`
- **Описание**: Добавляет всех существующих пользователей системы в выбранный отряд
- **Процесс**:
  1. Загрузка всех пользователей (пагинация по 100)
  2. Сбор всех UUID пользователей
  3. Массовое добавление через API
  4. Отображение результата

### Удаление всех пользователей
- **Кнопка**: `➖ Удалить ВСЕХ пользователей`
- **Описание**: Удаляет всех пользователей из выбранного отряда
- **Процесс**:
  1. Загрузка всех пользователей (пагинация по 100)
  2. Сбор всех UUID пользователей
  3. Массовое удаление через API
  4. Отображение результата

## Навигация

```
Отряды → Список отрядов → Выбор отряда
    ├── ➕ Добавить пользователей
    │   └── ➕ Добавить ВСЕХ пользователей
    └── ➖ Удалить пользователей
        └── ➖ Удалить ВСЕХ пользователей
```

## Технические детали

### API методы
- `add_users_to_squad(squad_uuid, user_uuids)` - добавление пользователей
- `remove_users_from_squad(squad_uuid, user_uuids)` - удаление пользователей
- `get_users(page, limit)` - получение списка пользователей

### Обработчики
- `squad_add_all_users` - обработчик массового добавления
- `squad_remove_all_users` - обработчик массового удаления

### Паттерны callback_data
- `squad_add_all:{squad_uuid}` - массовое добавление
- `squad_remove_all:{squad_uuid}` - массовое удаление
